# Cloudflare 优选IP

## 数据源
* 每 24 小时 自动构建 
* **ipv4.txt** 源采用  [VPS789](https://vps789.com/)
* **ipv6.txt** 源采用  [WeTestV6](https://www.wetest.vip/page/cloudflare/address_v6.html)
* **ym.txt** 源采用  [VPS789](https://vps789.com/)

## 使用
* ``ipv4.txt``
```shell
https://raw.githubusercontent.com/nngt886/cf-yx-ip/main/ipv4.txt
```
* ``ipv6.txt``
```shell
https://raw.githubusercontent.com/nngt886/cf-yx-ip/main/ipv6.txt
```
* ``ipv4+6.txt``
```shell
https://raw.githubusercontent.com/nngt886/cf-yx-ip/main/ipv4+6.txt
```
* ``ym.txt``
```shell
https://raw.githubusercontent.com/nngt886/cf-yx-ip/main/ym.txt
```
